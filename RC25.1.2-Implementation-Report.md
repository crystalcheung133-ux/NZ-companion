# RC25.1.2 Implementation Report

## Root cause
RC25.1 introduced a blocking Travel Engine integrity failure in `data.js`: the Day 5 item `queenstown-market-d5` was declared as a non-place item while also exposing a `map` action. `engine-integrity.js` correctly threw `NONPLACE_HAS_PLACE_ACTION` during data acceptance. Because `data.js` aborted at load time, later runtime files did not initialise, leaving Trip/Guide item actions undefined and the Days menu shell empty.

## Fix
- Removed the invalid `map` field from the non-place Queenstown Market timeline item.
- Preserved the market itinerary text and route context.
- Bumped runtime/cache tokens and service-worker release identity.
- Updated version, manifest and checksums.

## Scope
No itinerary order, booking information, Guide content, payment data or UI design was otherwise changed.
