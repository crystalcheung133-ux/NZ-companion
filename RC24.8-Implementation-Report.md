# RC24.8 Implementation Report

## Scope
Booking UX Freeze built from `NZ-Companion-RC24.7.5-Full-Deploy.zip`.

## Implemented
- Accommodation timeline action renamed from `🧳 Trip Info` to `🎟️ Booking`.
- Mobile alternative action shortened to `🔄 Options`; the original descriptive label remains in the button title.
- Accommodation booking details now use one consolidated Payment block.
- Tax, purchased date and room-price breakdown were removed from the during-trip accommodation UI.
- Payment block supports Paid, Pay at Hotel and pending states.
- Same-currency bookings show Total, Discount/Cashback and Net Cost.
- Mixed NZD/AUD bookings show the NZD total, approximate AUD total, AUD cashback and approximate AUD net cost.
- Planning conversion fixed at `1 NZD ≈ 0.84 AUD` for static trip estimates; the UI labels mixed-currency results with `≈` and a planning-estimate note.
- Accommodation list now prioritises Net Cost for quick comparison.
- Southwark parking updated to `Confirmed · NZD 15 · pay at hotel`.
- Sudima restored to `2:00 PM → 11:00 AM`, with generic confirmation placeholders removed from visible booking details.
- Service-worker cache and release version advanced to RC24.8.
