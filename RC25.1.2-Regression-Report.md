# RC25.1.2 Regression Report

## Confirmed root-cause verification
`engine-integrity.js` previously blocked `data.js` with `NONPLACE_HAS_PLACE_ACTION` for `queenstown-market-d5`. After correction, `data.js` passes the integrity acceptance stage.

## Expected restored behaviour
- Trip menu items can open their detail modal.
- Guide categories and cards can initialise and open.
- Days menu can populate instead of showing only an empty shell/handle.

## Limitation
The container browser is policy-blocked from loading localhost/file URLs, so real click automation could not be completed here. The fix targets the exact blocking runtime exception rather than CSS or cache symptoms.
