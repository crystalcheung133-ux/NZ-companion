# RC25.2.2 Implementation Report

## Scope

This corrective release addresses three confirmed issues only:

1. Day 4 Wānaka → Queenstown route choice.
2. Guide detail information hierarchy.
3. Ultimate Alpine Experience missing from the Activities Guide category.

## Changes

- Added two directly usable route buttons on Day 4:
  - Crown Range
  - Via Cromwell / SH6
- Added concise route-safety guidance for poor weather, darkness and possible ice.
- Moved Why Go / Why Stay, Suggested Dishes / Highlights, Trading or Opening Hours, Booking advice and practical sections inside the primary Guide information card.
- Removed duplicated large standalone content cards below the primary Guide card.
- Restored `ultimate-alpine` to both the Activities category and canonical `GUIDE_ORDER`.
- Added a focused RC25.2.2 CI contract.
