# RC25.2.1 Implementation Report

## Scope
Corrective runtime-integrity fix applied to the RC25.2 Guide Card Standardisation delivery.

## Root cause
`freshchoice-queenstown` and `queenstown-market` remained in the active `SHOP` Guide category but were omitted from `GUIDE_ORDER`. The production integrity layer therefore threw two blocking `REL_GUIDE_ENTRY_ORPHAN` errors while `data.js` loaded. Page shells rendered, but the downstream Trip, Guide and Day interaction runtimes never initialised.

## Fix
- Added `freshchoice-queenstown` and `queenstown-market` to canonical `GUIDE_ORDER`.
- Added `ci-tests/test-runtime-integrity.js`, which executes the real production integrity gate against `data.js`.
- Bumped HTML/runtime cache keys and service-worker cache identity to `rc25-2-1-integrity-fix`.
- Updated version, production manifest and checksums.

## Expected behaviour
- Trip popup lists open their selected detail records.
- Guide popup lists open their selected Guide cards.
- Days opens its full sheet rather than only the white handle.
