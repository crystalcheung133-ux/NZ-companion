# RC17.11 — Accommodation Price Integrity Fix

## Root cause
Accommodation prices remained intact in `BOOKINGS_DATA`, but Guide Cards read `PLACES.price`. Most stay places contained the placeholder `See Trip Info`; Edgewater was the only stay whose price had been copied into both sources.

## Fix
- Accommodation Guide Cards now treat the matching accommodation booking as the canonical commercial-data source.
- Current stay-place price fields were synchronized for all accommodation records.
- Added `accommodation-price-regression.test.js` to fail if an accommodation booking loses its price, its place relationship, or falls back to `See Trip Info`.
- Updated the service-worker cache key so deployed/PWA clients receive the corrected data and renderer.
