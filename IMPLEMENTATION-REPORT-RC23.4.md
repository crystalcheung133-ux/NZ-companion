# RC23.4 — Modal / Bottom Navigation Coexistence

## Fixed
- Long Trip and Guide cards now stop above the fixed bottom navigation.
- Previous / Next controls remain scrollable and visible.
- Selecting Guide while a Trip card is open closes the Trip overlay first.
- Selecting Trip while a Guide card is open closes the Guide overlay first.
- Days also closes any open Trip / Guide overlay before opening.

## Scope
No itinerary, booking, guide content, storage, expense or Studio behaviour was changed.
