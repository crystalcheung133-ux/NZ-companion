# RC25.2.3 Implementation Report

## Scope

This release is a narrow production-freeze patch for the fixed bottom navigation overlapping Trip Studio and Timeline Editor final actions.

## Changes

- Added a canonical admin modal layer above the fixed app navigation.
- Raised Timeline Editor and Trip Studio overlays to that layer.
- Protected the Timeline Editor action footer and mobile safe area.
- Added Studio sheet bottom safe-area and scroll clearance.
- Updated HTML cache keys and the service-worker cache identity.
- Added an RC25.2.3 focused CI contract.

## Data preservation

No itinerary, booking, guide, payment, route, or Supabase schema data was changed. A Timeline edit that was successfully published through Trip Studio remains in the existing Supabase published snapshot and continues to hydrate over this static deploy when compatible.
